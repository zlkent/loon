# 家庭 WG 本地参数解析器：测试版计划与进度

**Goal:** 手机填写一次家庭 WG 参数，更新公共完整配置时在本机合并；公共仓库不存私人参数。
**Architecture:** 独立 parser 插件通过 `[Argument]` 收集参数，JS 处理 `$resourceType == 0` 的指定公共配置。成功生成后，把参数存入 Loon 本地脚本存储；参数控件全空时可恢复该副本。无网络请求、无参数日志，不改变主订阅。
**Tech Stack:** Loon Build 1008 / 新版 Generic Script、纯 JavaScript、Node 内建 test/vm、现有 Python unittest。
**Spec / approval:** 用户已同意先做“手机参数填写一次，解析器自动合并”的可测试版本。本文件固化该小范围试验，不等于设备验收或正式切换。

## 范围与取舍

- 选择本机解析器；不把仓库转私有，不部署新服务，不把私钥或入口写进 Git。
- 目标固定 `192.168.1.0/24`；手机默认 `10.77.77.2`，端口默认 `51820`，MTU 1280。
- 输入手机私钥、ROS 公钥、可选 PSK、入口主机、家庭 SSID；SSID 不写进公开默认值。
- 家庭 SSID 直连，其余网络 WG；只更改家庭路径、相关 HTTP 绕过和全部节点筛选，保留 DNS / 美国服务池 / 其他规则。
- 保存副本是 Loon 脚本普通本地存储，不宣称 Keychain 或加密；其他脚本可能可读。备份与最终配置也含私钥。
- 参数错误、异常模板、重名节点、损坏标记、存储失败时不调用 `$done` 返回新配置，抛不含参数值的错误。App 如何呈现/处理更新失败仍待实测。
- 测试分支 `codex/wg-local-parameters` 提供候选插件；`main` 的基础配置保持原样。

## Review Focus

- 控件为空与部分填错必须区分，禁止新旧密钥静默混配。
- 重复更新不重复插入；已有私人订阅、证书不被脚本删除。
- HTTP 绕过只减去家庭网段，不把其他私网误接管；更具体 bypass 冲突应报错。
- 非配置或非指定 URL 不得获得私钥；日志、错误、通知不含参数。
- 解析器控件丢失时副本恢复、插件条目保留、解析器关联仍需手机确认。
